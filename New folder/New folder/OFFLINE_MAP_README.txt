TRAVORA OFFLINE REAL ROAD MAP
==============================

Map data:
- File: maps/travora-west.pmtiles
- Area: 73.052,18.51 to 73.798,18.99
- Source: OpenStreetMap
- Extract: BBBike
- Tile schema: Shortbread

IMPORTANT:
This PMTiles file contains real geographical vector-road data for the extracted area.
It is NOT a schematic map.

Run:
1. Open this project in VS Code.
2. Start Live Server.
3. Open offline-map.html through http://127.0.0.1:5500/...
4. Keep internet available the first time so MapLibre GL JS and PMTiles JS can load from their CDN.
5. The map data itself is local in maps/travora-west.pmtiles.

The current extract does NOT cover all of Maharashtra. It mainly covers the Mumbai-Alibag-Lonavala/western area inside the BBBike rectangle.
